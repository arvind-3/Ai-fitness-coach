AI Fitness Coach is a browser-based intelligent workout assistant that uses real-time pose detection to analyze user movements and provide instant corrective feedback. The system leverages TensorFlow.js for client-side machine learning inference, ensuring low latency and privacy-focused processing without requiring server-side computation.

The application includes a structured workout generator, calorie and macro calculator, authentication system using Firebase, and personalized workout tracking. The architecture is modular and scalable, designed to support future enhancements such as progress analytics and performance scoring.

Tech Stack: JavaScript, TensorFlow.js, Tailwind CSS, Firebase
Key Focus Areas: Real-time ML inference, UI responsiveness, user experience, modular design
